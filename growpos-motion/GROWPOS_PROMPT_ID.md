# Brief produksi GrowPOS — Everything Flows V3

## Fakta produk yang dipakai

GrowPOS adalah POS SaaS untuk usaha Indonesia. Sumber UI otentik untuk video ini adalah rekaman demo lokal berukuran 1600×900, 30 fps, sepanjang 26,97 detik. Rekaman menampilkan kasir/katalog/keranjang, stok, dan laporan operasional. Akun yang terlihat adalah **Kedai Senja Demo** dengan data fiktif.

Gunakan angka hanya sebagaimana terlihat di UI demo. Jangan menyebut data demo sebagai hasil pelanggan, jangan menyamakan penjualan dengan laba bersih, dan jangan menyatakan pembayaran berhasil jika konfirmasi tidak terlihat. UI ponsel, audio berlisensi, dan URL publik yang diverifikasi tidak tersedia untuk produksi ini.

## Arahan V3

- Reels vertikal 9:16, 1080×1920, 60 fps, durasi 28 detik, H.264 MP4.
- Bahasa Indonesia; pesan akhir **“Satu Sistem, Tumbuh Bersama.”**
- Konsep **ONE FLOW** menyatukan sinyal pembuka, interaksi kasir sungguhan, pergerakan kamera 3D melalui layar laptop, stok, laporan, dan hero brand.
- Pakai laptop saja. Tidak ada mockup ponsel karena capture mobile asli tidak tersedia.
- Tampilkan logo GrowPOS yang ada di project. Jangan tampilkan URL tanpa sumber resmi yang dapat diverifikasi.
- UI hanya berasal dari rekaman lokal tersebut. Jangan menggambar ulang fitur atau merekayasa angka/interaksi.
- Render gerak berbasis frame dan deterministik. Periksa contact sheet serta frame transisi sebelum menyatakan render selesai.
