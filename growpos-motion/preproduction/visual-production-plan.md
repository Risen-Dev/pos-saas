# GrowPOS — Visual Production Plan

## Status

Pra-produksi visual selesai untuk enam keyframe konsep. Tidak ada animasi, komponen Remotion baru, render, atau MP4 yang dibuat. Arah visual dan materi autentik perlu dikunci sebelum produksi penuh.

## Hasil audit dan keputusan

- Pertahankan hijau GrowPOS `#17694D`, antarmuka kasir akurat, nominal transaksi sah, dan tipografi UI yang sebenarnya.
- Bangun bahasa visual dari still-life kedai gelap, amber hangat, hijau botani, depth-of-field, perangkat fisik, serta negative space editorial.
- Gunakan perspektif/3D untuk perangkat, tangan, meja, properti, dan lapisan kaca. UI/data tetap 2D tajam di bidang layar.
- Hindari satu screenshot full-frame, laptop polos di tengah, kartu placeholder besar, zoom sebagai gerak utama, dan dashboard rekaan.
- Alur visual: katalog → pemilihan produk → pesanan/total → ringkasan bisnis → hero lintas perangkat.

## Aset prioritas berikutnya

1. Ambil capture responsif katalog/cart dari aplikasi pada lebar ponsel nyata menggunakan transaksi demo yang sama.
2. Siapkan foto produk asli dengan pencahayaan satu keluarga; hindari fallback inisial bila foto produk menjadi fokus.
3. Sediakan packshot perangkat dan clean plate layar untuk terminal, laptop, tablet, dan ponsel.
4. Siapkan wordmark resmi, font overlay yang disetujui, dan safe area 9:16.
5. Ambil capture UI tanpa cursor tutorial/toast bila tidak dibutuhkan; pastikan nama bisnis/data aman untuk publikasi.
6. Sediakan footage/model release tangan kasir dan lokasi, atau satu lokasi pengambilan untuk menjaga kontinuitas cahaya.

## Panduan fotografi dan komposit

- Master akhir dapat disiapkan pada 2160 × 3840 atau lebih tinggi, lalu diturunkan ke 1080 × 1920. Keyframe review saat ini 1080 × 1920.
- Selaraskan empat sudut capture dengan bidang layar; tambahkan bezel occlusion, pantulan rendah, falloff, grain optik, dan color spill secukupnya. Jangan ubah warna teks/harga UI.
- Pakai matte terpisah untuk tangan/perangkat foreground. Jangan gunakan matte warna kasar dari still konsep pada master final.
- Sisakan headline di area gelap yang rata; UI berada di bidang layar dan tidak melintas ke keyboard/bezel.
- Jaga label dan harga cukup besar untuk preview ponsel. Pilih crop relevan bila satu halaman penuh mengecilkan UI.
- Gerak kamera harus melayani fokus. Elemen UI independen punya asal, tujuan, dan respons yang jelas; hindari bouncing dan fade generik.
- Hindari parallax pada data. Produk, badge item, cart, subtotal/diskon/total, KPI bergerak sebagai lapisan 2D dalam layar. Kedalaman berlaku untuk perangkat dan lingkungan.

## Kriteria persetujuan sebelum produksi penuh

- Keenam still disetujui sebagai satu identitas warna, tipografi, cahaya, dan fotografi.
- Pemilik produk memvalidasi capture mobile responsif, teks, nilai transaksi, merek, dan screen state.
- Foto produk/packshot nyata tersedia atau pendekatan visual konsep disetujui untuk dipertahankan.
- Frame 02 tidak lagi menunjukkan tepi matte kasar; corner fit, brightness, dan occlusion semua layar terasa wajar.
- Headline serta UI terbaca pada preview ponsel dan tidak ada ruang kosong yang terasa tidak sengaja.
- Alur antarkeyframe disetujui sebelum animatic atau komponen animasi dibuat.
